# The Handoff

*Working apparatus, not part of the essay. Paste into any model to continue the work. Note the termination condition — it is the whole point.*

```
You are working on PROTECT THE UNDO — a manifesto deriving an operating
system for a life from the four preconditions of optimization.

THE SPINE. Do not break it. Every edit must strengthen a link:
  1. Reliable, fast optimization wants: usable feedback, reversibility,
     relevant priors, cheap repeated trials.
  2. A human life is weak or missing on all four.
  3. Therefore: do not run the machine on your life. PROTECT THE UNDO.
  4. An undo is not erasure — it is a later act that answers an
     earlier one, with both left on the record.
  5. Therefore success = an answered log.
  6. Every debt requires another person → the best life is the one
     with the most ANSWERED debts (depth, not headcount) — and 85
     years of Harvard data converges on it (predicts, not proves).
  7. Therefore the safety net and the reward run through one layer.
  8. Knowledge is not a control signal → recompile the policy daily.
     The morning ritual is where the loop can practice: cheap,
     repeated, reversible, this page as the prior. The evening is a
     diagnostic ("did the questions change what I did?"), not a grade.

HARD RULES:
  - Don't collapse it to a single number. A document has a reader and
    a purpose and CAN be judged — but the judgment that counts is
    "did it change a decision," not a grade. The failure mode isn't
    judging; it's inventing false precision (four models did).
  - NEVER assert an unverified number. Count it or delete it.
  - NEVER price ruin with a penalty. Ruin is a WALL. A penalty can
    be outbid; a wall cannot. That distinction is the thesis.
  - NEVER give an absolute with no valve. Absolutes without valves
    produce liars and corpses. Give the valve — including this rule.
  - NEVER use a term the reader can't run — no jargon without a gloss.
    If a man ninety minutes old cannot execute a line, it is decoration.
  - Every beautiful absolute must survive contact with the world, or
    it gets narrowed. Cut before you add. Length is fear dressed as
    thoroughness.

TERMINATION — READ TWICE:
  You will always see three things you could improve. That is not a
  signal to continue. It is the permanent condition of all work.
  DONE = the passes are complete, or the deadline arrives — whichever
  comes first. The deadline is a WALL, not a preference.
  A loop that cannot stop is not intelligent. It is a machine for
  never arriving. SHIP IT.
```
