# CRUZ — Frontier Command Center (the true 10/10 plan)
*Direction set by the three references: an immersive, living, holographic command center. We adopt that aesthetic, unify it across client + broker + operator, and hold it to the best UI/UX bar — jaw-dropping AND usable. (We keep the orb; we ignore the mockup's bottom nav.)*

---

## THE ONE BIG DECISION
**Move from "calm light client + dark consoles" (two registers) to ONE immersive dark "Command Center" shell across all three roles.** Same living globe, same orbital orb, same glassy dark surfaces, same glowing mono numbers. Role = content, not chrome.

### …governed by THE LEGIBILITY LAW (what keeps it top-tier UX, not just pretty)
Customs work is data-dense. So the drama **frames** the data, never fights it:
- **Immersive surfaces** (Summary / Command / Login / Landing): full holographic globe + glass + orbital orb. Jaw-dropping.
- **Work surfaces** (Tráficos, Pedimentos, Files, Classify): same dark spine, but the globe recedes to an **ambient edge-glow**, and tables sit on **solid dark-glass** with high-contrast mono text. Always-legible.
- Glow is a *semantic* spend (live / risk / AI), never decoration. Contrast tested on every surface (AA).

---

## THE SIGNATURE ELEMENTS (the "how" of jaw-dropping)

### 1. The Living Globe — the soul of the product
A real 3D Earth (night-lights/satellite), slow auto-rotation, with:
- **Animated trade-lane arcs** (teal→amber = predicted delay) between labeled hubs — Laredo, Long Beach, Rotterdam, Singapore, Hong Kong.
- **Pulsing crossing nodes**; a floating **LAREDO CROSSING INDEX 120 ▲** readout.
- On overview screens it's the hero; on work screens it's a dim ambient sphere bleeding off the right edge.
- Interactive: hover a node → that corridor's live status; it's the same component on login, landing, and every role dashboard.

### 2. The Orbital Orb — the AI made physical
Keep our orb; add **orbital rings** + a soft ground-glow so it reads as a living presence, center-anchored. It's the copilot entry on every surface, with the 6-state machine intact.

### 3. Holographic glass + Priority Beacons
- **Glassy dark cards:** translucent navy, subtle top-inner highlight, hairline border, soft outer glow — the stat cards and panels from the reference.
- **Priority Beacon:** the red-light card gets a glowing border + backdrop blur + "Open file" — the most urgent thing on screen literally glows. One at a time.

### 4. Ambient intelligence cues
- **Voice-ready search** with a live waveform (the reference's header), ⌘K, "Ask CRUZ anything…".
- A quiet **"Frontier Model"** signature; LIVE/STAGED honesty dots; semáforo everywhere.

## HONEST FLAGS
- **Performance:** a real 3D globe + glass blur must stay 60fps and degrade gracefully (static sphere fallback) on weak devices/mobile — engineered, not assumed.
- **Legibility risk:** going dark-immersive everywhere is the right *wow*, but only survives if the Legibility Law is enforced screen-by-screen. That discipline is the difference between "Gemini concept art" and "shippable frontier product."
- **The mockups are concept art** (typos, garbled text): we take the *aesthetic*, not the literal copy — and we keep CRUZ's honesty law (no invented numbers).
