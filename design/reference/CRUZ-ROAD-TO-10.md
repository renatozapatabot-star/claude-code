# CRUZ — The Road to a True 10/10 (research-grounded)
*Current honest aggregate: ~8.6. This plan closes the exact gaps, every move backed by 2026 evidence on agentic-AI UX, Apple/iOS craft, and B2B landing conversion.*

## WHAT THE RESEARCH SAYS (and how CRUZ must answer it)

### A. Agentic-AI UX — trust is the product
- **Three-level transparency: what / how / why, via progressive disclosure** — "trust through understanding, not blind faith." Plus confidence visualization, source attribution, AI-content markers.
- **Override architecture + confidence signaling + graceful error recovery + progressive delegation** are the four pillars enterprise agent UIs are judged on in 2026.
- **Separate thinking from doing** (planning visible before action) is what makes agents feel trustworthy.
- **Governance is foundational, not an add-on** — the winning posture is "designed together, model → agent → tooling."
→ *CRUZ already has the bones (trace, confidence routing, 3-option pause, audit). The gap is making what/how/why a consistent, tappable layer on EVERY number and action, and letting autonomy be earned (progressive delegation), not fixed.*

### B. Apple / iOS 2026 craft — "feel it when you pick it up"
- **Liquid Glass:** glass is a **spatial separator meaning "this floats above content," never decoration.** Used for ONE purpose, consistently. Readability must survive every background.
- **Glanceable design:** communicate critical status in ~1.5s, before any interaction. (We have answer-first heroes — extend everywhere.)
- **Adaptive layouts are not optional** across phone → tablet → desktop.
- **Haptics / micro-feedback as a communication layer** — confirm actions, signal state, without looking.
- **Premium = depth, clarity, refined motion, restraint** — sensed in motion, not screenshots.

### C. B2B landing conversion (the lowest-rated surface, 7.8)
- **Single primary CTA converts ~13.5% vs ~10.5% multi-CTA.** One job per page.
- **5-second clarity test:** what / who / why-it-matters in 5s; **benefit headline < 44 chars.**
- **Social proof + compliance/audit badges above the fold, next to the CTA** (76% of top pages show logos above fold).
- **Bento grids** for complex products; **interactive/guided demos replace static screenshots.**
- **Mobile-first** (~80%+ of B2B research is on mobile); **load < 2–3s**; **≤5 form fields.**

## THE 10/10 PLAN (sequenced, each phase shippable)

### PHASE 1 — Finish the client app (kills the unevenness, the #1 drag)
1. **Bring every tab to the Tráficos bar:** answer-first/glanceable hero, semáforo pills (done), alive tables, progressive disclosure — Indicadores → Pedimentos → Files → Warehouse → Annex 24 → Monthly Report → MVE → Search → Alerts.
2. **Global typography lock** (one scale, weights 600/500/450, mono numbers) applied app-wide — no over-bold pockets.
3. **State parity:** empty / loading-skeleton / error each as crafted as the populated state.
4. **Liquid-glass discipline:** the orb panel + any floating layer use glass = "floats above," tested for contrast on every background; flat surfaces stay flat.

### PHASE 2 — Make trust tappable everywhere (the agentic moat, visible)
5. **What/How/Why on demand** on every key number and agent action (extend the "Why this fracción?" pattern): tap → source + last-sync + reasoning. Provenance becomes universal, not sampled.
6. **Progressive delegation UI:** autonomy is *earned* — CRUZ shows its track record and proposes more autonomy as confidence/history justify, user grants per-scope.
7. **Confidence + recovery consistency:** every proposal carries a confidence read; every failure shows what broke + the drafted recovery.

### PHASE 3 — The landing becomes a conversion asset (7.8 → 9.5)
8. **One job, one CTA** ("See CRUZ clear a load") + 5-second-clarity benefit headline < 44 chars.
9. **Trust band above the fold, beside the CTA:** the one human signature, 5-yr audit trail, 5-second cancel, shadow mode, "0 filed without sign-off" — compliance-grade reassurance where buyers look first.
10. **Bento feature grid** + **interactive guided demo** (the two-sided "watch CRUZ clear it" moment) replacing static screenshots.
11. **Mobile-first rebuild**, load < 2.5s, the living globe tuned for small screens.

### PHASE 4 — Adaptive + tactile (the "picked it up" feeling)
12. **Adaptive layouts** verified phone (375) → tablet → desktop on every surface; bottom-tab native feel on mobile.
13. **Micro-feedback layer:** crisp confirm states on GO/sign/approve (visual "tap" + optimistic instant response, no spinners) — speed as a feature.
14. **One motion grammar** (150/250/400ms, status-bearing loaders, shared-element row→detail morph), reduced-motion safe.

### PHASE 5 — The frontier substance (the ceiling: "looks frontier" → "is frontier")
15. **Real per-load reasoning** via live model calls (trace varies by actual load, not a script).
16. **One genuinely live regulated feed** (DOF FX / e.conta) — the only item needing credentials; the true moat.
17. **Append-only audit** any reviewer can open from any number.

### PHASE 6 — Re-sync + exit artifacts
18. **Re-sync broker / operator / login** to the finished client reference (already ~9; keep pixel-consistent).
19. **The exit artifacts** — cleared-doc PDF + status email, typeset and screenshot-worthy (design as the GTM channel).
