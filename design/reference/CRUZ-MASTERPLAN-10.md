## PART 2 — THE GAPS (current → 10/10)

**A. The moat is invisible where it matters most.** 2026 AI buyers need assurance about *reviewability, governance, and failure boundaries* — they balance speed promises against oversight. CRUZ HAS this (honesty law, the gate, confidence routing, escalate-to-broker, shadow mode) but the **landing barely says it**. The consensus that "the system around the model beats the raw model — routing, retrieval, human escalation" is CRUZ's exact architecture; it should be the headline, not a footnote.

**B. Two fabricated numbers still exist** (login "99.2% success", landing ROI). On a product whose entire brand is "never fake a number," these are self-inflicted. Fix to LIVE/STAGED/honest-empty.

**C. It still doesn't *act*.** Trace runs on a timer; no real model call; zero live feeds. This is the ceiling on "frontier."

**D. Motion is not yet a grammar.** Count-up + breathing orb exist, but transitions between views/states aren't a consistent system (2026: motion is structure — what just happened, what's happening, what's next).

**E. Accessibility unproven.** Glass + muted-on-navy needs an AA audit; glass is known to hurt contrast. 2026 treats AA as a quality gate, not compliance.

**F. Landing is missing 2026 table stakes:** one primary CTA discipline, bento feature grid, an interactive/guided demo (not static screenshots), GEO/answer-engine optimization, mobile-first (≈83% of visits).

**G. Role-adaptive density + full cross-tenant book** not yet built.

**H. Frontier-aesthetic credibility** under-leveraged: the "Technical Mono" builder aesthetic (mono for more than numbers, grid structure, wireframe/ASCII embellishment) would signal technical authenticity to exactly CRUZ's audience — used sparingly so the almanac stays calm.

## PART 3 — THE 10/10 MASTER PLAN

### 0. Lock the aesthetic direction (north star)
**"The measured-honest console."** Terminal = a precise, dense, monospace-credible cockpit (lean into Space Mono for labels/IDs/eyebrows, hairline grids, a faint dot-grid backdrop) — frontier-builder authenticity without coldness. Almanac = calm evolved-glass paper, warm and possessive. **The brand is the honesty law made visible** — every surface shows LIVE/STAGED/honest-empty, the human gate, and confidence routing as *design features*, because that is the exact thing 2026 AI buyers are scanning for. One accent (cyan) = live/healthy only. Bento everywhere complex. Dark-as-default for the desk (enterprise signal).

### 1. LANDING (7.0 → 10) — *the conversion + positioning surface*
- **Reposition the headline to the moat:** lead with "CRUZ does the labor; a licensed broker holds the pen" — speed *with* oversight, not speed alone. FAB copy (feature→advantage→benefit), action-first single CTA ("See a clearance run", not "Submit"). One primary CTA, subtract competing ones.
- **Bento feature grid** replacing stacked sections — modular, scannable for a complex feature set.
- **Interactive guided demo** embedded (not static screenshots): the two-sided clearance playing across broker + client, scrubable — interactive demos now replace screenshots.
- **Trust band:** an explicit "reviewability · governance · failure boundaries" section (the 5s cancel, the audit trail, shadow mode, the one signature) — the exact assurances AI buyers need.
- **Honesty everywhere:** replace any fabricated stat with LIVE/STAGED or an honest-empty ("measured as we run").
- **GEO + mobile-first:** structured content for AI answer engines; 375px-first layout.
- *Acceptance:* one CTA; bento renders; the guided demo plays; zero fabricated numbers; AA contrast; 375px clean.

### 2. LOGIN (8.5 → 10)
- **Kill the fabricated "99.2%"** — swap for an honest LIVE/STAGED metric or the corridor index only.
- **Goal-first whisper:** the companion demo ends with "tell me what you need to clear" → routes into the right role-app pre-pinned. Onboarding asks the outcome, not just credentials.
- *Acceptance:* no fabricated number on screen; goal entry routes by role with the dock pre-pinned.

### 3. CLIENT — CRUZ.dc.html (8.0 → 10)
- **Wire the `data-kpi` count-up** (already hooked, never fired) — carefully, around existing living-data timers.
- **Role-adaptive density:** finance/warehouse/cliente get density + module order tuned to role without manual setup (2026: context-aware layouts adapt to who's logged in).
- **Per-section hero polish** + AA pass on glass/muted text.
- **Possessive copy audit** ("your document, your terms" — never a compliance countdown).
- *Acceptance:* KPIs count up; switching role re-densifies; AA passes; every hero distinct.

### 4. BROKER CONSOLE (8.5 → 10)
- **Full cross-tenant book** as its own view-router screen (every client under the patente, dense + calm, semáforo per tenant, honest-empty cells, drill-in).
- **Anomaly-first strip** (mirror the operator) — "what changed across the patente since you looked."
- **Expandable labeled rail** (match the client's nav richness) + the command bar executing real agent actions.
- *Acceptance:* book view renders cross-tenant with provenance; anomaly strip present; rail expands.

### 5. OPERATOR COCKPIT (8.7 → 10)
- **Real reasoning per object** (Tier-0 dependency) so the trace differs per load.
- **Keyboard velocity layer** (j/k rows, G=GO, number tabs) beyond ⌘K.
- *Acceptance:* trace varies by load; full keyboard nav works.

### 6. SHARED COPILOT DOCK (8.3 → 10)
- **Real model calls** via `window.claude.complete` with graceful fallback — variable steps, real confidence.
- **Live mini-globe inside the orb** (port the login globe, throttled) for pixel-identical brand.
- *Acceptance:* dock reasons live; orb shows the living globe.

### 7. CROSS-CUTTING SYSTEM (the finishing layer that separates 9 from 10)
- **Motion grammar:** one documented set — 150 hover / 250 panel / 400 page, shared-element morph on row→detail, status-bearing micro-interactions (trace accelerates near done, skeletons shape-matched), all reduced-motion safe. Motion explains *what just happened / is happening / next*.
- **Provenance everywhere:** every number tappable → source + last-sync (extend the broker pattern to all surfaces; make it a tap popover, not just hover, for mobile).
- **Accessibility as a gate:** AA contrast on every accent-on-surface + glass-muted pair, focus-visible, keyboard parity, motion sensitivity — by default.
- **The two-sided live moment:** one load animating across broker terminal AND client almanac at once, no reload — the signature demo, reusable on the landing.
- **Bilingual + 375px** verified on every surface (contact sheet × {375,1440} × {broker,client} × {ES,EN}).

### 8. THE TWO BACKEND MOATS (uncertifiable in-tool — the literal ceiling)
- **One genuinely live regulated feed** (DOF FX or e.conta) → one real LIVE badge with real last-sync.
- **Real model reasoning** behind the trace + classification.

## DEFINITION OF 10/10
A cold reviewer — phone and laptop, ES and EN, as broker / operator / shipper / prospect — lands on a page that says *what CRUZ uniquely guarantees* (labor by AI, pen by a licensed human), watches the AI **actually reason on real data**, controls its autonomy, sees **every number cite its source**, never finds a fabricated stat, a contrast failure, a dead state, or a screen that doesn't fit — and the broker holds the one irreplaceable signature. The system around the model — not the model — is the product, and it's visibly, beautifully honest.
