# CRUZ — the five-day sprint (demo → sell → build)

Goal: real money committed by Friday — service agreements and founding-program deposits —
using the Claude-design demo as the closer. Nothing on this list requires writing code.

## Day 1 — Package (morning) + list (afternoon)

- [ ] Deploy `site/` to a real URL (`npx vercel deploy site --prod`) and test on a phone.
- [ ] Payment link for the USD 2,500 founder deposit (Stripe) + SPEI details for MX clients.
- [ ] Founder confirms every `[CONFIRMAR]` price in `pricing.md`; print 10 copies.
- [ ] Print 5 copies of `order-form-loi.md` (after counsel's read).
- [ ] Build the target list — three tabs:
  - **A. Current clients** (upsell/referral): every active account.
  - **B. Lapsed clients** (win-back): everyone who crossed with the house in the last 5 years.
  - **C. Prospects**: importers/maquilas on the corridor the founder knows by name.
- [ ] Record the 40-second screen capture: landing hero → four keys → GO → the gate.

## Day 2 — Outreach

- [ ] Send segment-A messages (WhatsApp first, `outreach-templates.md`) — all of them.
- [ ] Send segment-B win-backs.
- [ ] Send the first 15 segment-C emails, personalized (route, cargo, a name).
- [ ] Book every reply straight into 30-minute demo slots for Days 3–4. Target: **8+ demos.**

## Days 3–4 — Demos, back to back

- [ ] Run `demo-script.md` verbatim beats, audience-picked depth. Phone moment always.
- [ ] Close in the room: signed order form + deposit link sent while sitting together.
- [ ] Same-day follow-up email: 3 lines + pricing sheet + payment link + "5 slots, viernes."
- [ ] T+1 WhatsApp nudge to every demo that didn't sign.

## Day 5 — Close everything open

- [ ] Call (don't email) every open demo before noon: "¿Aparto su lugar o lo suelto?"
- [ ] Founder pricing genuinely expires today — say it and mean it.
- [ ] Countersign, collect deposits, calendar each founding client's kickoff call (≤7 days out).
- [ ] Log results: demos run / closes / deposits / total service revenue committed.

## Scoreboard (fill in Friday night)

| Metric | Target | Actual |
|---|---|---|
| Demos run | 8 | |
| Founding deposits (USD 2,500) | 3–5 | |
| Service agreements (despacho/bodega/cross-dock) | 2–3 | |
| Referrals asked for / received | every demo | |

## Then: build (the philosophy)

Monday after: every founding client gets a kickoff call; what they need first becomes the
build queue — in `DESIGN_LOG.md`, one slice at a time, demo-quality bar (`scripts/cruz-loop.md`).
We never build ahead of a signature again.
